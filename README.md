# API Produtos

API REST desenvolvida com **Java e Spring Boot** para gerenciamento de produtos.

## Funcionalidades

* GET - Listar produtos
* GET - Buscar produto por ID
* POST - Adicionar produto
* PATCH - Atualizar produto
* DELETE - Remover produto

Os produtos são armazenados em memória, sem utilização de banco de dados.

## Como executar

Execute a classe `ApiProdutosApplication` no IntelliJ e acesse:

`http://localhost:8080/produtos`
